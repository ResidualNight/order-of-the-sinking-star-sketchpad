# StarSketch · 沉星之序游戏内草稿纸

![草稿纸Pro · 沉星之序游戏内草稿纸](docs/images/starsketch-cover.png)

An in-game sketchpad for **[Order of the Sinking Star](https://store.steampowered.com/app/499170/Order_of_the_Sinking_Star/)** on Windows x64 / DirectX 12.

在游戏画面上自由画线、画箭头、放置星标和连续编号，并用半透明棋盘辅助观察。网格直接读取游戏数据和相机透视，支持临时选择相机。独立制作，非游戏官方组件。

**当前版本：0.2.3 测试版。** 增加独立场景相机来源，原方案继续备用，两种方法都无可用网格才报定位错误。支持常见 4:3、5:4、16:9、16:10、21:9、32:9 的候选预览，以及铺满、居中黑边和居中裁剪映射。开启网格不自动弹出选择窗口，检查主画布预览后点击“采用候选网格”；Shift+G 仍主动打开列表。新增错误反馈与诊断复制。用户已安装测试并反馈正常，更多电脑和关卡仍需实测。见 [0.2.3 发布说明](https://github.com/ResidualNight/order-of-the-sinking-star-sketchpad/releases/tag/v0.2.3-test)。

## 下载与安装

**推荐使用可视化安装包。** 两种 ZIP 内的游戏功能与 DLL 完全相同，均为 0.2.3 测试版，无需安装开发环境。请从 [0.2.3 Release](https://github.com/ResidualNight/order-of-the-sinking-star-sketchpad/releases/tag/v0.2.3-test) 的 **Assets** 下载下面的玩家 ZIP；GitHub 自动生成的 **Source code** 是开发源码，不是安装包。

| 方式 | 下载文件 | 适合的操作 |
| --- | --- | --- |
| 可视化安装 / 更新 / 卸载（推荐） | [StarSketch-0.2.3-installer.zip](https://github.com/ResidualNight/order-of-the-sinking-star-sketchpad/releases/download/v0.2.3-test/StarSketch-0.2.3-installer.zip) | 选择游戏文件夹，安装、检查插件更新或卸载 |
| 直接复制文件与文件夹 | [StarSketch-0.2.3-r67271-test.zip](https://github.com/ResidualNight/order-of-the-sinking-star-sketchpad/releases/download/v0.2.3-test/StarSketch-0.2.3-r67271-test.zip) | 自己将 DLL 和资源文件夹复制到游戏目录 |

### 方式一：可视化安装 / 卸载

1. 保存进度并退出游戏，将 `StarSketch-0.2.3-installer.zip` **完整解压到一个单独文件夹**，不要在压缩包里直接打开 EXE，也不要只提取 EXE。
2. 双击 `StarSketch-安装卸载.exe`，也可使用同目录的 `StarSketch-安装卸载.cmd`。
3. 浏览选择或粘贴游戏安装文件夹，里面应直接包含 `sinking_star.exe`。可在 Steam 库中右键游戏 → 管理 → 浏览本地文件找到它。
4. 点击“检查目录”，确认选对游戏目录后点击“安装 / 更新”，等待安装成功提示。
5. 照常从 Steam 启动游戏，默认按 **E** 打开草稿纸；已改过进入键时使用保存的键位。

安装器打开时自动从本项目 GitHub Release 检查新版，也可点击“检查插件更新”。发现新版会询问是否更新；选择“是”后自动下载、校验并更新，选择“否”不改动安装。测试版更新也会被识别，版本相同或更旧时不覆盖。

无法在线更新时，可点击窗口下方“打开 GitHub 发布页手动下载”，下载新版完整安装 ZIP 后按上述步骤更新。联网失败不影响本包的“安装 / 更新”和卸载。

游戏目录保留 `StarSketch-Manager/StarSketch-安装卸载.cmd`，删除原下载包后仍可检查更新或卸载。旧 0.1.2 管理器需要先下载本版安装器更新一次，之后即可在线更新。工具按安装记录和文件哈希处理自身文件，保留游戏、存档和无关文件；游戏运行时拒绝替换。已知手动安装的 0.1.1 / 0.1.2 也可更新或卸载。详见 [安装工具说明](docs/安装工具说明.md)。

**现有 0.1.2 用户：** 使用新版完整安装器选择原游戏目录，点击“检查目录”识别手动版/安装器版；可直接“安装 / 更新”，无需先卸载，也可直接“卸载草稿纸”。旧 0.1.2 管理入口没有在线更新功能，需要先用新版完整安装器更新一次。游戏和存档保留；未知或修改过的文件不会被强行覆盖/删除。

### 方式二：直接复制文件与文件夹（继续保留）

1. 保存进度并退出游戏，解压 `StarSketch-0.2.3-r67271-test.zip`。
2. 将包内的 **`dxgi.dll` 和整个 `StarSketch-assets/` 文件夹**复制到 `sinking_star.exe` 同级目录；不要在中间多套一层解压文件夹。
3. 保留包内的使用说明和 `licenses/`，照常从 Steam 启动游戏，按 **E** 打开草稿纸。

复制后的位置应如下：

```text
游戏安装文件夹/
├─ sinking_star.exe
├─ dxgi.dll
└─ StarSketch-assets/
   └─ NotoSerifSC.ttf
```

手动更新时退出游戏，再替换本工具的 DLL 和资源。手动卸载时退出游戏，移除本工具的 `dxgi.dll` 及 `StarSketch-assets/` 内的原字体；有自行添加的文件时请保留，不必删除其他说明、许可证或游戏文件。此方式无需运行安装脚本。

两种方式均需先退出游戏再安装、更新或卸载。若游戏目录已有其他模组的 `dxgi.dll`，请先处理兼容性，不要直接覆盖；可视化工具遇到未知 DXGI、已修改的安装文件或路径链接会停止操作，不会关闭游戏。

## 操作

内部渲染比例与窗口不同的候选仍需确认。待确认时在“网格精调”选择显示方式；场景相机可指定实际游戏画面比例，原方案使用读取到的内部比例。例如 2560×1600 窗口中的 2560×1440 居中画面，选择 16:9 +“居中黑边”。不自动识别黑边，贴合后采用；映射和网格只在本次会话保留。

以下为 0.2.3 的默认键位；旧版编号星标现拆分为 P 星标和 N 编号。除进入/退出外，工具快捷键只在绘画模式下生效。

| 按键 | 功能 |
| --- | --- |
| E | 进入 / 退出绘画 |
| B | 自由画笔，左键拖动 |
| A | 箭头，左键拖动确定两端 |
| P | 无编号星标，左键单击放置 |
| N | 独立编号，黑色描边、白色加粗衬线字；吸附有效时按住左键滑动连续放置 |
| N+C | 后续编号重新从 1 开始，保留现有标记，可撤销 |
| 按住右键 | 局部擦除笔迹，整枚删除箭头、星标和编号 |
| G | 网格显示及箭头 / 星标 / 编号格心吸附 |
| T | 全屏半透明棋盘染色 |
| Shift+G | 临时选择相机：切换候选预览，按需翻转/调整高度，再本次采用 |
| C | 清空标记，保留网格与染色，可撤销 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Esc | 取消当前笔画 / 校准，或返回游戏 |

主界面保留常用工具与选色；大小、粗细、透明度、自定义色编辑放在“键位与设置”。主界面提供重新识别和手动校准；仅开启“网格与吸附”时显示可展开的“网格精调”。默认没有使用 F1–F12。点击“键位与设置”可更改进入/退出、工具、网格、校准、清空、撤销、重做及按住擦除；支持 Ctrl/Alt/Shift 组合和 F1–F12，也可录入两个普通键组成的快捷键，单键松开确认；Esc 固定用于取消/关闭，重复组合不会覆盖原分配。擦除可改为键盘键或鼠标右/中键。

画笔、箭头和星标共用红、白、蓝及两个自定义色格；后两个色格可在“键位与设置”的“画笔、标记与颜色”中通过 RGB、HEX 或拾色器编辑。编号从 1 递增，擦除不重排，清空重置，撤销/重做恢复序号。开启网格与吸附且定位/校准已确认时，可按住左键滑过格子快速编号；一次拖动每格只编号一次，快速跨越会补齐中间格，一次撤销取消整次拖动。N+C 同时按住可让后续编号重新从 1 开始，已有编号原样保留；不需要先按哪一个键。为防止组合误触，默认 N、C 单独使用时在松开后执行。颜色修改只影响之后的标记。键位、颜色及其他偏好永久保存，重启游戏后恢复。

“键位与设置”提供“切换关卡自动清除标注”，初始默认关闭，会永久记住选择。开启后，可信新关卡连续稳定确认才清空标记并从 1 编号，可撤销；加载中、读取失败、同尺寸但身份未变、开关草稿纸或调整分辨率都不会触发清空。

已有标记始终固定在屏幕上，退出绘画后继续显示；退出游戏后不保存草稿。中文输入法仅在本游戏窗口内禁用，不修改系统布局或其他应用。

## 网格与适用范围

0.2.3 将游戏版本差异显示为灰色 [SS-GRID-001] 兼容性提示，未知或更高版本仍继续尝试识别和关卡监测，实际数据布局与相机仍须通过校验。它读取逻辑网格与可用的角色高度层，通过场景姿态或原方案的新鲜相机帧生成透视网格，无需识别地砖纹理；场景来源无需栈样本，仍须手动确认贴合。按 E 打开草稿纸时自动定位，不要求先启用网格或染色；已经手动采用的会话网格会继续沿用。游戏渲染尺寸或画布尺寸变化后，等待尺寸稳定 250ms 再自动定位。连续切换会取消前一次未完成的定位，使用最新尺寸。定位等待或失败时暂停旧自动网格的吸附与染色；一般绘画期间冻结网格。

Shift+G 打开“临时选择相机”：切换候选预览，可翻转或调整高度，贴合后点击“本次采用”直接启用当前网格。开关绘画面板保留本次吸附；再次打开列表后取消会恢复原网格。主动重新识别、确认切关卡或画面尺寸变化清除旧网格；关卡待确认时暂停吸附，确认仍在原关卡后恢复。三点、四点校准已移除，跨关卡相机学习尚未实现。详见 [临时选择说明](docs/临时相机选择说明.md)。

原数据网格已在 r67271 / Steam Build 26006400 的 `torc_blocked` 小关卡、3840×2160 实机验证；每次打开与稳定调整分辨率后刷新已在主世界普通斜俯视下的 3840×2160 ↔ 3200×1800 验证。0.2.0 跨关卡自动清除仍需更多实机覆盖，其他关卡、多层角色、分辨率和图形模组组合尚未全面验证。方向异常校验通过数值回归，先前报告的翻转现场尚未实机复现。详见 [验证记录](docs/验证记录.md)。

多个角色分层时，默认选择投影位置最接近屏幕中心的角色层，可在“网格精调”覆盖高度或恢复角色层。数据失效会暂停旧自动结果的吸附；有可用候选时可临时选择相机。主世界 Tab/Q 地图视角不在本版支持目标内。

## 从源码构建

0.1.3 起报错带固定编号，例如 `[SS-GRID-006]` 表示等待新相机帧超时，`[SS-GRID-011]` 表示本次发现方向异常的相机候选。0.2.3 对通过其余校验的新帧先显示方向预览，可在“网格精调”中上下/左右翻转并“确认并记住”，确认前暂停吸附与染色。方向选项随设置保存，不移动已有标注。反馈时提供完整编号、触发操作和关卡/分辨率；详见 [错误代码](docs/错误代码.md)。

需要 Windows x64、PowerShell 5.1+ 和网络连接（首次获取编译器）。依赖源码与字体已经包含在仓库，工具链不进入 Git 历史。

```powershell
.\setup.ps1
.\build.ps1
.\package.ps1
# 可选：从上一步的玩家 ZIP 生成图形安装包
.\package-installer.ps1
# 安装器回归：仅操作 work/ 内的隔离目录
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\installer_tests.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\update_tests.ps1
```

已有 LLVM-MinGW 20251021 工具链时：

```powershell
.\build.ps1 -ToolchainPath '你的 llvm-mingw 工具链目录'
```

`build.ps1` 编译 DLL、核心测试、相机栈测试、更新提醒测试、界面生命周期测试和旧图像诊断工具，并运行四组测试。产物在 `build/`；`package.ps1` 生成仅包含玩家运行文件、说明和许可证的 ZIP 到 `dist/`。默认构建不会启动游戏或替换已安装的 DLL。

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `src/` | DXGI/DX12、标记模型、界面、只读游戏数据定位 |
| `tests/` | 核心、相机栈、更新提醒、界面生命周期与安装器回归，数字相机样本及诊断源码 |
| `installer/` | 图形窗口、安装/卸载模块及原生启动器源码 |
| `docs/` | [功能规格](docs/功能规格.md)、[网格实现](docs/网格数据方案评估.md)、[验证记录](docs/验证记录.md)、[更新记录](docs/更新记录.md) |
| `assets/` | Noto Serif SC 字体与许可证 |
| `third_party/` | 构建需要的 ImGui 源码与来源记录 |

本地认证、工具链、构建结果、游戏截图、游戏提取数据和研究日志均被排除。玩家二进制通过 Releases 分发，不放进源码历史。
