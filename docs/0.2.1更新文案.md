# StarSketch 0.2.1 测试版

## 修复自动网格识别

- 游戏版本校验改为灰色兼容性提示：未验证或更新的游戏版本仍会尝试识别和关卡监测，继续校验实际数据布局、相机及帧更新；具体识别错误单独显示。
- 支持游戏的原尺寸、一半尺寸及固定 720P、1080P、1440P、4K 内部渲染档位，包括内部渲染大于窗口的情况；网格仍投影到完整输出画布。
- 相机扫描改为分块读取已提交可读的线程栈区域，跳过保护页和不可读区域，不再因整栈读取失败或超过 8 MiB 而丢弃整条线程；跨块数据保持完整。
- 识别失败日志增加线程/内存访问、尺寸筛选、矩阵/方向校验及帧号/时间推进的具体拒绝原因；每次失败带请求编号、进程编号、UTC 时间、实际阈值和最多 6 条有限数值样本。诊断自动启用，不改变相机采用规则，不记录完整内存、矩阵、草稿或截图。

多用户 SS-GRID-010 反馈的共同根因尚需受影响电脑验证，以上回归不代表所有现场问题已解决。

## 手动修正网格方向

- 仅方向校验失败、其余校验和新帧通过时，显示候选网格，首次确认前暂停吸附与棋盘染色；同轮正常候选仍优先采用。
- 在“网格精调”中提供上下翻转、左右翻转、恢复原始方向及“确认并记住”。翻转保留完整透视，已有屏幕标注不移动。
- 确认后的方向随设置保存，同类方向下重新识别、重新进入或重启后复用；正常相机不会自动继承另一类异常相机的翻转。仅保存选项，不保存临时网格几何。
- 删除三点、四点校准及四点说明框，Shift+G 与原自定义键位改为“临时选择相机”：短时采集、合并重复视图、切换网格预览，支持临时翻转和高度调整。
- “本次采用”直接接受当前可用预览、关闭选择窗口并启用吸附，不再因临时相机地址/新帧复核报 012；预览期间暂停吸附、染色及画布标注操作。
- 已采用的网格保留在本次游戏会话中，开关绘画面板继续沿用；主动重新定位或确认关卡/画面尺寸变化后才清除。不写入磁盘，也不改写原方向偏好；跨关卡相似匹配仍未实现。[临时选择操作说明](临时相机选择说明.md)。
- 再次打开选择器后取消会恢复原网格，刷新候选不丢失原备份；关卡待确认期间暂停吸附、染色与精调，切换 G/T 不再丢失保留的网格。修复最小化时的无效界面尺寸与极端透视下的坐标越界风险。
- 相机偏移 860 的整数字段不再误作浮点校验，避免合法整数位模式被当作 NaN 拒绝；尚未证明它是用户现场报错的原因。

## 游戏内更新提醒

- 后台读取项目官方 GitHub 发布订阅，包含测试版；界面初始化后检查，随后每 30 分钟复查。
- 按数字版本比较，发现更高版本并确认官方安装 ZIP 与清单可用后，在主面板最上方显示绿色提醒：“发现新版本 X，请退出游戏后使用安装器更新”。
- 无更新、联网失败或发布信息无效时静默，不显示检查状态或错误，不影响绘画。
- 游戏内只检查并提示；退出游戏后，仍由安装器下载、校验并安装新版。

继续支持原版 0.1.2 直接升级，保留已发布版本及本地测试版 DLL 的归属识别。草稿、撤销历史和校准几何仍只在本次会话中保存。

安装与更新请使用 [v0.2.1-test 发布页](https://github.com/ResidualNight/order-of-the-sinking-star-sketchpad/releases/tag/v0.2.1-test) 的玩家 ZIP；安装器和手动复制包使用同一份 0.2.1 DLL。原 0.1.2 用户可直接升级，无需先卸载。完整操作见 [README](../README.md)。
