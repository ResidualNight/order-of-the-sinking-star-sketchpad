# 沉星草稿 StarSketch 0.2.0 更新说明

这一版主要更新了键位自定义、标记样式和连续编号，并加入设置保存与可选的跨关卡自动清除功能。

- **游戏内自定义键位**：在默认 E 呼出的界面中打开“键位与设置”，即可修改工具及操作快捷键。支持单键、Ctrl / Alt / Shift 组合，以及 N+C 这样的双普通键；提供冲突提示和恢复默认键位。
- **设置自动保存**：修改后的键位、颜色、大小、粗细、透明度等偏好会自动保存，退出并重新启动游戏后仍然保留。草稿内容和临时网格校准仍只保留在当前游戏会话中。
- **更多画线颜色**：保留红、白、蓝三个基础色，新增两个可自定义色格，支持拾色器、RGB 和 HEX 输入。画笔、箭头和星标共用选色，已有标记不会随色格修改而变色。
- **星标样式更新**：星标取消自带编号，使用当前画笔颜色，并加入复古金边、明暗斜面和更厚重的阴影。
- **独立编号工具**：默认按 N 切换，使用贴近游戏风格的加粗衬线数字，外黑内白，大小可单独调整。在已确认的网格吸附下，按住左键滑动即可连续编号，快速跨格自动补齐，一次拖动可整体撤销。
- **保留旧编号重新计数**：默认同时按住 N+C，让后续编号从 1 开始，已有标记保持原样。该操作支持改键、撤销和重做；为避免组合误触，默认 N、C 单独使用时在松开后执行。
- **可选的跨关卡自动清除**：在“键位与设置”中开启，初始默认关闭并记住选择。确认切换关卡后清空标注、重新从 1 编号，可撤销；加载中或无法确认关卡时保留标注。
- **界面整理**：大小、透明度、自定义色等设置集中到“键位与设置”。“网格精调”保留在主界面，仅开启“网格与吸附”后显示。
- **安装与更新优化**：针对 0.1.2 手动版和安装器版完善识别、直接更新与卸载流程，无需先卸载再升级；旧 0.1.2 管理器需先用新版完整安装器更新一次。修复 GitHub API 限流时更新检查直接失败的问题，加入备用检查路径、更明确的错误提示，以及窗口下方常驻的 GitHub 发布页手动下载入口。

## 安装与升级

推荐下载 Assets 中的 `StarSketch-0.2.0-installer.zip`，不要选择自动生成的 Source code 源码包。

1. 保存进度并退出游戏，把安装 ZIP 完整解压到单独文件夹。
2. 双击 `StarSketch-安装卸载.exe`，也可用同目录 CMD 启动。
3. 选择直接包含 `sinking_star.exe` 的游戏目录，点击“检查目录”，再点击“安装 / 更新”。Steam 库中右键游戏 → 管理 → 浏览本地文件，可以找到游戏目录。
4. 等待安装成功后从 Steam 启动游戏，默认按 E 打开草稿纸；改过进入键的用户使用保存的键位。

0.1.2 用户可使用本版完整安装器直接升级，无需先卸载；升级后可从游戏目录 `StarSketch-Manager` 再次打开管理器。自动更新失败时，使用窗口下方的 GitHub 发布页入口手动下载新版完整安装包。

手动安装包 `StarSketch-0.2.0-r67271-test.zip` 继续提供：退出游戏后，将 `dxgi.dll` 和整个 `StarSketch-assets` 文件夹复制到 `sinking_star.exe` 同级，保留说明和许可证。已有其他模组的 DXGI 时请先处理兼容性。

本版仍以当前已验证的游戏版本为基础，未扩大自动网格的实机支持范围；跨关卡自动识别仍需更多游戏内验证。
