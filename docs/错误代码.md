# 错误代码

更新日期：2026-10-25（Asia/Shanghai）。错误编号从 0.1.3 起提供，旧 0.1.2 安装包使用原提示。

## 反馈方式

报错以 `[SS-类别-编号]` 开头。反馈时保留完整编号和提示，附上发生操作、关卡、分辨率及是否刚切换地图/窗口。游戏目录内的 `StarSketch.log` 会记录相同网格错误编号、内部诊断名和定位时的渲染尺寸；只需提供出错附近的行。

旧提示“数据定位未就绪，请重试或按 Shift+G 手动校准”合并了下面的 GRID-006、007、008、009；其中相机等待超时现在进一步分出 GRID-010。仅凭旧截图无法区分原因。

## 游戏数据网格

编号表示失败的检查位置，不一定能单独确定根因。普通游戏视角下点击“重新识别”可重试；失败期间保留几何预览，暂停旧网格吸附及染色，手动校准仍可使用。

| 编号 | 内部诊断名 | 含义及排查方向 |
| --- | --- | --- |
| SS-GRID-001 | unsupported_game_build | 游戏完整 SHA256 不匹配或校验失败；自动数据读取停用，使用手动校准。 |
| SS-GRID-002 | active_entity_manager_unavailable | 未读到当前关卡管理器；确认已进入可操作关卡。 |
| SS-GRID-003 | settings_array_unavailable | 关卡设置数组不可读或数量/容量校验失败。 |
| SS-GRID-004 | settings_grid_invalid | Settings 类型、归属、尺寸或格子数量校验失败。 |
| SS-GRID-005 | actor_layer_unavailable | 未取得有效角色高度层，且未设置高度覆盖。 |
| SS-GRID-006 | fresh_camera_frame_unavailable | 1.8 秒内没有取得有效的新相机帧，超时时仍有候选地址；候选不保证持续有效。 |
| SS-GRID-007 | visible_actor_layer_unavailable | 相机数据有效，但没有可用于选择高度层的可见角色。 |
| SS-GRID-008 | level_changed_during_localization | 定位期间关卡管理器改变或失效，拒绝采用跨关卡结果。 |
| SS-GRID-009 | projected_grid_invalid | 当前相机和高度层不能生成有效投影网格。 |
| SS-GRID-010 | validated_camera_unavailable | 等待超时时没有通过校验的相机候选；可能与视角、渲染尺寸或暂时无法读取相机有关。Tab/Q 地图视角仍不支持。 |
| SS-GRID-011 | camera_orientation_invalid | 本次定位发现翻转或方向异常的相机候选，拒绝采用后未能取得正常新帧。返回普通斜俯视后重新识别，或手动校准。 |
| SS-GRID-099 | unknown_game_grid_error | 未分类的定位失败兜底，反馈完整日志。 |

方向校验同时检查地面投影的朝向和世界向上的屏幕方向，拒绝上下/左右镜像及整体倒置；允许正常镜头绕竖直轴旋转，不限制某一网格步长必须朝屏幕上方。扫描会继续寻找正常候选；失败时暂停旧网格的自动吸附和染色，不自行翻转矩阵，也不改变手动校准。

## 图像诊断与手动校准

旧图像算法仅留作诊断，不会在数据定位失败后自动启用。

| 编号 | 含义 |
| --- | --- |
| SS-IMAGE-001 | 图像网格可信度不足，候选结果需要用户确认。 |
| SS-IMAGE-002 | 图像识别未产生可靠结果；已有确认网格仍保留。 |
| SS-IMAGE-003 | 捕获画面格式不受图像诊断支持。 |
| SS-CAL-001 | 三点或四点校准不能生成有效网格，重新按顺序选点。 |

| 编号 | 含义 |
| --- | --- |
| SS-DX12-001 | DirectX 调用失败，后面附操作名与 HRESULT。 |
| SS-DX12-002 | 捕获到渲染异常，叠加层停用。 |

| SS-HOOK-002 | DXGI 工厂挂钩失败。 |

安装和回滚阶段继续使用 SS-INSTALL 编号；网络故障不阻止离线安装和卸载。

## 维护规则

- 新增玩家可见错误必须在提示最前面放稳定编号，相关日志使用相同编号。成功和正常等待提示无需错误编号。
- 编号不因文案或代码顺序调整而变化，不得挪用旧编号表达其他原因。
- 运行时网格错误使用 `src/errors.hpp` 的类型与注册表；在检测失败处设置类型，界面和日志共享格式。
- 同步维护本表，并验证失败状态、重试清除错误编号、手动校准接管及未知异常兜底。
