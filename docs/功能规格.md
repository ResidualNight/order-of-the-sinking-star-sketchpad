# 功能规格

版本：0.2.0 测试版，下载见 GitHub Release。更新日期：2026-10-25（Asia/Shanghai）。本文描述当前源码实现，历史变化见更新记录。

## 交付与状态

Windows x64 / DX12 的独立 DXGI 代理。玩家将 DLL 和字体资源复制到游戏程序同级目录后，照常启动即可加载；无需外置进程和开发环境。网格验证范围以 [验证记录](验证记录.md) 为准。

## 可视化安装与卸载

- 完整解压安装包后打开图形 EXE 或 CMD，由用户浏览选择或粘贴游戏安装文件夹，必须直接包含 `sinking_star.exe`。
- 提供安装/更新、卸载及只读目录检查。游戏运行时拒绝写入，不自动结束进程。
- 本版图形安装包与手动包使用同一 0.2.0 DLL，包含字体、使用说明及全部第三方许可证；安装记录保存工具自身文件路径和 SHA256，不记录草稿。
- 识别已知 0.1.1/0.1.2 手动安装。明确显示 0.1.2 手动版或安装器版、直接升级无需先卸载、直接卸载及旧管理器不支持在线更新的操作提示；卸载结果显示移除的版本。遇到未知 DXGI、修改后的已登记文件、路径链接或损坏负载时停止。
- 安装/卸载以事务暂存和备份支持失败还原；卸载保留游戏、存档和无关文件，只移除归属明确且未修改的文件及空目录。
- 安装回滚失败时先保留恢复备份，空目录清理异常不影响这一决定；窗口显示清理警告，并从后台异常中保留原始错误编号。
- 游戏目录保留 `StarSketch-Manager` 管理入口，原下载包被删除后仍可在线更新及卸载。旧 0.1.2 管理入口需先用本版完整安装包更新一次。
- 打开窗口时后台检查本项目 GitHub Release，提供“检查插件更新”按钮；识别正式版与 -test 测试版，按数字版本比较。发现新版询问用户，确认后下载并校验官方资产、ZIP SHA256、版本/DLL 身份和负载，复用所有权检查及事务回滚；版本相同或更旧不覆盖。下载、解包和安装均限制在所选游戏目录内，失败时保留原安装，不直接运行下载脚本。
- 使用系统 Windows PowerShell 5.1 与 .NET Framework，不修改系统执行策略，不要求 Python。在线检查/更新需访问 GitHub；联网失败不阻止本地安装与卸载。

## 标记与会话

- 笔迹、箭头、星标和独立编号保存屏幕坐标，不随角色或镜头移动。
- 退出绘画后仍显示标记；退出游戏后清空全部会话，不保存或恢复草稿。
- 画笔自由绘制，不吸附；箭头起终点、星标及编号在网格已确认时吸附格心。
- 右键按下擦除，拖动连续擦除，松开恢复原工具。笔迹局部擦除，箭头、星标与编号整枚删除。
- 吸附开启、网格已确认且可用时，编号左键按住滑动连续放置；按格子半格边界遍历快速移动经过的中间格，斜向恰好穿角只进入斜向格。一次手势每格一次，整组撤销/重做。经过 UI 或视口外断开连线；失去有效吸附、换工具、退出或重新定位时结束当前组，等待新的点击，不在未可信网格上继续填号。
- 星标不显示编号，内部使用所选颜色，轮廓采用深褐外沿、旧金色斜面、细高光和两层厚重投影。独立编号从 1 递增；删除中间编号不重排；C 清空后从 1 开始，撤销恢复原编号。
- 撤销与重做覆盖标记操作。C 只清空标记，保留网格与染色，可撤销。
- 标记和棋盘染色半透明，选色保留在主界面，大小、粗细、透明度、自定义色放在“键位与设置”。“网格精调”放在主界面，仅开启“网格与吸附”时显示可展开标题，无可用网格时禁用精调控件。
- 红、白、蓝加两个可自定义 RGB/HEX/拾色器色格；画笔、箭头、星标共用选色，仅新标记使用更改后的颜色。
- 编号固定黑边白字，使用与游戏参考图风格相近的 Noto Serif SC 衬线字形、独立高精度数字字库和加粗绘制；多位数字按宽度缩放，星标/编号分别调整大小。

## 切换关卡与偏好设置

- “键位与设置”中的自动清除初始默认关闭，选择持久保存。每 200ms 只读监测，退出绘画后继续工作；至少三次有效样本且连续稳定 500ms 后确认（正常约 600ms），长时间无采样或读取失效重置候选，不清空旧标注。
- 关卡特征来自校验后的 Settings 持久实体 ID、sound_level_name、行列与角点；读取前必须匹配 r67271 完整可执行文件 SHA256，读取时验证归属/类型/大小/数组/格子数量/销毁状态，前后复核防止混入加载中的不同对象。对象分配地址不参与身份比较，相同格子数量也能区分特征不同的关卡。
- 第一次稳定识别仅建立基线，短暂候选、读取失败、开关界面、镜头、手动校准和分辨率变化不触发清空。失去可信关卡时暂停旧吸附与定位；确认切换或原关卡恢复后重新请求网格。
- 确认切换时按开关决定是否清空标注/重置计数，保持键位、颜色、尺寸、透明度与网格/染色开关；自动清空纳入撤销历史。在关闭自动清除期间仍更新关卡基线，重新开启不会补清已经确认切换后的标记。
- 这是保守的设置特征识别：若关卡名不可读/为空或两个关卡的全部特征完全相同，保留标注，允许 C 手动清空。尚未增加真实跨关卡实机覆盖，不将合成读取器/状态机回归当成全关卡验证。

## 自动与手动网格

- 自动定位读取版本校验后的关卡 Settings、Guy 高度及主视图矩阵，完整处理斜俯视透视。
- 相机候选除逆矩阵和视口校验外，还检查地面投影朝向及世界向上的屏幕方向，拒绝镜像和倒置。允许正常镜头水平旋转；发现异常后继续寻找正常候选，最终失败显示 SS-GRID-011，暂停旧网格吸附/染色，保留手动校准。
- 每次使用进入键（默认 E）打开草稿纸都请求定位，包括首次打开、网格/染色关闭、上一轮失败或使用过手动网格的情况。
- 检测实际渲染尺寸与画布尺寸变化，稳定 250ms 后重新定位；连续变化合并请求，取消前一次未完成的定位。
- 每次请求先暂停旧几何的吸附与染色，新结果通过游戏数据校验后恢复。一般绘画期间冻结网格，分辨率变化会刷新。
- 默认取屏幕中心附近角色所在的高度层；提供高度覆盖与恢复角色层按钮。
- 定位等待或数据失效时保留几何预览，暂停吸附与染色，允许重试、主动采用或手动校准。
- 手动四点：设置列数与行数，再选左上、右上、右下、左下外角。
- 快速三点：选择格心、横向相邻格心、纵向相邻格心。
- 精调：基点、两个方向步长、透视参数、倍增/减半格距。手动调整会取消正在等待的自动定位；再次打开草稿纸或改变分辨率会重新定位，并在成功时采用新结果。
- T 按格子深浅双色交错铺满游戏视口，不做逐格自由涂色或可通行性分析。
- 不包含求解、路线自动计算或自动操作角色。

## 按键

默认：E 进入/退出；B 画笔；A 箭头；P 星标；N 独立编号；N+C 后续编号从 1 开始（保留原标记）；按住右键擦除；G 网格和吸附；T 染色；Shift+G 四点校准；C 清空；Ctrl+Z/Y 撤销/重做；Esc 取消或返回。

工具快捷键仅在绘画模式处理，游戏模式恢复游戏按键。默认不占用 F1–F12。

工具栏“键位与设置”打开独立窗口，支持修改上述动作及按住擦除；键盘支持字母、数字、F1–F12、方向/导航和常用符号键，也支持两个普通键同时按住，搭配 Ctrl/Alt/Shift，擦除还可选鼠标右/中键。Esc 保留用于取消/关闭，左键保留绘制/放置。组合冲突提示 SS-INPUT-001 并记同码日志，不覆盖原分配。可恢复默认，键帽、进入提示和操作提示同步使用当前绑定。单键录入在松开后确认，双键可同帧按下，组合冲突比较忽略普通键先后。

“编号从 1 开始”默认 N+C，也有工具栏按钮；仅重置后续计数，现有编号不改动，重置纳入撤销历史。双键动作优先并消费组成键，避免触发 C 清空；参与双键的单键动作在释放时确认。按住擦除不能与双键组合的单键前缀共享同一分配，以免组合前先擦掉标记。

录入期间不执行工具动作或画布操作；关闭窗口后等待按键/鼠标及修饰键释放，避免录入键立即执行。文本输入或拾色器活动时暂停快捷键。键位和偏好永久保存到当前 Windows 用户的 `%LOCALAPPDATA%\StarSketch\settings.ini`；使用稳定动作名、虚拟键码和显式格式版本，支持对调键位、双普通键及修饰键。只保存自动清除、选色与两个自定义色、粗细/大小/透明度、网格/染色开关；不保存标记、编号计数、历史或校准几何。修改稳定 500ms 后写入，关闭设置、退出绘画、失焦或正常关闭游戏时提前保存；同目录临时文件写入并刷新后原子替换。坏配置暂用默认并保留原文件，首次主动修改后另存坏文件备份；读写失败显示并记录 SS-CONFIG-001/002。

## 界面与输入

深蓝灰底、旧金色双层键帽边框、衬线字与八角星芒标记与黑边白字编号，工具栏位于画面边缘。原始游戏参考截图只保留在本地，不作为发布资产。

绘画模式隔离游戏的原始输入和按键轮询。IME 只在游戏窗口内禁用，窗口销毁时恢复关联；不修改其他应用或系统布局。

## 错误反馈

玩家可见报错前显示稳定的 `[SS-类别-编号]`；定位失败细分原因，界面与日志使用相同编号。安装器及更新错误保留独立编号，未知系统异常使用兜底编号。编号表及反馈方式见 [错误代码](错误代码.md)。
