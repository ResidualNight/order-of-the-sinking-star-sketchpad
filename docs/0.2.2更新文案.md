# StarSketch 0.2.2 测试版

本次补充相机候选的尺寸关系、采集时序和用途区分，保留原有绘画、临时选择与会话网格功能。

## 相机识别修复

- 补充四分之一输出尺寸的候选，例如输出 3840×2160、内部 960×540。每个候选仍须通过数值、矩阵、地图、关卡和新帧检查。
- 在叠加层每帧调用前采集有效新帧，扫描中新发现的完整有效副本立即保留，降低临时来源随后被覆盖的影响。
- 有界追踪同投影的新临时地址。使用上一轮最新基线判断新帧，同轮旧副本不能互相证明新鲜度，静止数据不能给过期副本续期。
- 正常主视图提示优先，已知反射等辅助用途不会被自动识别采用。只有辅助新帧时显示 `[SS-GRID-013]`，可返回普通游戏视角重试，或临时选择相机检查贴合。

## 临时选择相机

- 主视图提示优先排列，辅助用途单独标记并提醒检查翻转和高度。尺寸不同、用途和完整投影相同的副本合并。
- 反射用途单独支持已实测的“内部场景尺寸 × 1/2 或 1/4”，覆盖相对输出为 1/6、1/8、1/12 等复合关系，仅供手动检查；不会将任意比例加入普通相机规则。
- 点击“本次采用”继续直接使用当前可用预览、关闭列表并保留吸附；重新选择后取消会恢复此前采用的网格。几何与临时翻转/高度仍只保留在本次会话。

辅助视图不能保证只靠翻转就恢复主视图，请检查整个画面的网格与高度。更多操作见 [临时相机选择说明](临时相机选择说明.md)。

## 安装与更新

正常退出游戏，完整解压 `StarSketch-0.2.2-installer.zip` 并运行图形安装入口更新。原 0.1.2 可直接升级，无需先卸载；0.1.3 及以上管理器支持检查更新。手动复制包与安装包使用同一份 0.2.2 DLL。旧发布附件保留。

游戏内更新检查保持静默，发现更高版本且官方安装附件可用时在面板顶部提示；游戏内不下载或安装。启动日志保留 `camera capture fix 20261027`，版本号为 0.2.2。

## 验证范围

本地四组 C++ 回归（含 23 输出/529 尺寸组合）、16 组安装器回归及隔离升级/卸载验证已通过；最终发布包另核验原始 0.1.2 的 11 组兼容回归与文件哈希。没有新 DLL 的受影响机器或更多关卡贴合验收。远端日志中的反射来源仍是推断，不能宣称所有 SS-GRID-010 均已解决。
