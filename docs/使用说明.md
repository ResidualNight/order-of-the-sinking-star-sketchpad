# 沉星草稿 StarSketch 0.2.4 测试版

0.2.4 测试版：优先尝试“场景相机·试用”，原方案保留备用。自动识别找到可用候选后立即采用并开启吸附，无需重复点击；棋盘染色按 T 开关生效。两种方法都没有可用网格才报定位错误。点击“使用原方案”可让本次识别优先使用旧方法，失败时仍由场景相机兜底。

构建标记包含 `game build 26249670 compatibility 20261030` 和 `automatic candidate snapping 20261030`。本包适配 2026-10-30 更新后的 Steam build 26249670，同时保留旧 r67271 读取路径与自动吸附。自动采用不弹出相机选择窗口。Shift+G 或“临时选择相机”仍主动打开完整选择器，切换候选、翻转或调高度后点击“本次采用”。请在普通游戏视角检查贴合，地图或过场画面请返回后重新识别；辅助候选不保证对应当前主视角。

屏幕比例适配：支持常见 4:3、5:4、16:9、16:10、21:9（2560×1080 / 3440×1440）、32:9。默认按当前窗口显示。在“网格精调”中选择“铺满窗口 / 居中黑边 / 居中裁剪”，场景相机还可选择实际游戏画面比例；主画布调整立即生效，临时选择器内调整后点击“本次采用”。不会自动识别黑边或裁剪方式。例如 2560×1600 窗口中上下各有 80 像素黑边时，场景候选选 16:9 和“居中黑边”；原方案使用读取到的内部比例。切换比例或显示方式会重置下方精调，请先选显示方式再调格距。取消相机选择会恢复原网格与比例调整入口。选择仅本次有效，重新识别、调整窗口尺寸或确认切关后重置，不保存几何信息。非居中的显示区域尚未专门适配。

本版补充四分之一视口并改进有效新相机帧的采集。相机筛选支持与屏幕一致、一半、四分之一尺寸和固定 720P/1080P/1440P/4K 档位，内部渲染与窗口输出分别处理，网格仍映射到完整窗口。可用的恢复候选也会自动采用，仍可通过临时选择相机调整。界面初始化后后台检查本项目 GitHub 发布订阅，之后每 30 分钟复查，包含测试版。只有发现比当前 0.2.4 更高的版本且官方安装 ZIP/清单可用时，主面板最上方才显示绿色“发现新版本 X，请退出游戏后使用安装器更新”。无更新、无法联网或发布信息无效时不显示更新提示，不影响绘画；不会在游戏内下载或替换 DLL。安装器仍负责下载、校验和安装。

相机失败诊断自动写入游戏目录的 StarSketch.log。诊断增强构建的启动标记含 camera diagnostics 20261026；报错后会记录同一 pid/grid_request 的完整失败组，区分尺寸、矩阵、方向和新帧等原因。反馈时发送启动标记及完整失败组，或直接发送日志文件即可，无需手动开启调试。日志不记录完整内存、矩阵、草稿或截图。

推荐下载并完整解压 StarSketch-0.2.4-installer.zip，打开 StarSketch-安装卸载.exe（或同目录 CMD），选择直接包含 sinking_star.exe 的游戏文件夹，保存进度并退出游戏后点击“检查目录”和“安装 / 更新”。0.1.2 用户也可直接升级，无需先卸载；旧版管理器没有在线更新功能，先使用新版完整安装器更新一次。

选择手动安装时，解压 StarSketch-0.2.4-r67271-test.zip，退出游戏后将 dxgi.dll 和整个 StarSketch-assets 文件夹放到 sinking_star.exe 同级目录，保留说明与许可证，照常从 Steam 启动。请下载玩家 ZIP，而非 GitHub 自动生成的 Source code 源码包。
若已经安装其他使用 dxgi.dll 的模组，请先处理兼容性，不要直接覆盖。

E 进入/退出绘画；B 画笔；A 箭头；P 星标；N 独立编号（黑边白字、加粗衬线字体）；N+C 后续编号从 1 开始并保留原标记；左键操作；按住右键擦除；G 网格和吸附；T 全屏半透明棋盘染色；Shift+G 临时选择相机；C 清空标记但保留网格和染色；Ctrl+Z/Y 撤销/重做；Esc 取消或返回。默认工具键只在绘画模式生效，没有占用 F1–F12。

在 E 呼出的工具栏点击“键位与设置”，点击对应按键后输入新组合，可搭配 Ctrl/Alt/Shift，也支持 F1–F12，以及 N+C 这样的两个普通键；单键松开确认，双键同时按住录入。冲突以 [SS-INPUT-001] 提示并保留原键位，Esc 取消录入/关闭窗口，可恢复默认。进入/退出键也能更改，提示同步显示；擦除可改为键盘键或鼠标右/中键，绘制/放置仍使用左键。

红、白、蓝为固定基础色，后两个色格在“键位与设置”→“画笔、标记与颜色”中通过 RGB、HEX 或拾色器自定义；画笔、箭头与无编号金边星标共用此选色，已有标记不随色格变化。独立编号固定黑色描边、白色加粗衬线字，参考游戏界面字形；默认 N 切换，点击放置，从 1 递增，擦除不重排，清空重置，撤销/重做恢复序号。在网格吸附开启且已确认时，编号工具支持按住左键滑动连续编号，快速跨格自动补齐，一次拖动每格只放一次；整次拖动合为一次撤销。未开启吸附或定位尚未确认时仍为单击放置。拖过工具栏或画布外暂停，回到画布后从当前格继续，不补连接空档。

同时按住 N+C 可将下一次编号重置为 1，已有编号保留，重置可撤销/重做；先按 N 或先按 C 均可，不会清空标记。默认 N 和 C 单独操作在松开时确认。重置动作也可在“键位与设置”中另设组合，或点击工具栏“编号从 1 开始”。

星标与编号分别调整大小。按键、自动清除开关、颜色、画笔/橡皮/标记大小、透明度及网格/染色开关会自动保存到 `%LOCALAPPDATA%\StarSketch\settings.ini`，下次启动恢复。草稿、撤销历史和临时网格校准不保存。

“键位与设置”统一放置不常用的大小、透明度与自定义色。网格精调放在主界面，仅开启“网格与吸附”时显示，点击标题展开；尚无可用网格时精调控件禁用。“切换关卡自动清除标注”初始默认关闭，开启后退出绘画仍会监测；新关卡特征通过校验并稳定确认后清空标记、从 1 编号，可撤销。加载中或无法确认时保留标注，重新打开草稿纸和改变分辨率不会被当作切换关卡。未验证的游戏版本仍会尝试监测，实际关卡数据与稳定性校验失败时保留标注；仍可按 C 手动清空。

自动网格读取当前关卡、角色高度与相机透视。使用进入键（默认 E）打开草稿纸自动定位；已自动或手动采用的临时网格会在本次会话保留，开关面板沿用；分辨率变化并稳定 250ms 后自动重新定位。连续切换使用最新尺寸，等待和失败时暂停旧网格吸附及染色。一般绘画期间网格冻结。网格精调提供高度覆盖与恢复角色层，另有临时相机选择；三点、四点校准已删除。已有标记固定屏幕，退出游戏不保存。IME 只在本游戏窗口内禁用。

临时选择相机（默认 Shift+G）：程序短时采集候选并合并重复视图。点击列表或上一项/下一项切换预览，可上下/左右翻转或指定高度层，贴合后点击“本次采用”。点击后立即关闭选择窗口，按当前预览渲染并启用吸附，不再复读相机地址或等待新帧，也不因这项复核报 012。预览期间不吸附、不染色、不绘制或擦除标注。可刷新候选，Esc 或关闭窗口取消。

本地修复版：相机在定位期间后台采集。自动路径未能取得完整匹配结果时，只要本请求有通过候选检查的可用网格，就自动采用并启用吸附；不会仅因显示候选而报 SS-GRID-015。无法显示可用网格时保留具体失败提示。重新识别或定位失败会使旧网格不可用，避免再次采用过期几何。

采用后的网格保留在本次游戏会话中，关闭并重新打开绘画面板继续沿用。重新打开选择器时暂存原网格；刷新候选不覆盖备份，取消或退出绘画会恢复原网格，新选择只有点击“本次采用”才替换它。主动重新识别、确认切关卡或调整画面尺寸会清除网格和备份。关卡数据暂不可用时暂停吸附、染色和精调，确认仍在同一关卡后恢复；切换 G/T 不会丢失原网格。最小化窗口保留网格、标注和撤销历史。网格不会保存到磁盘，也不改写原方向或自动高度设置。没有可用预览时按钮禁用。详见 docs/临时相机选择说明.md。

当前只核验 r67271 / Steam Build 26006400 的一个小关卡和 3840×2160。其他关卡、分层角色和分辨率尚未全面验证。游戏版本未验证或版本校验失败时，面板单独显示灰色 [SS-GRID-001] 提示，仍继续尝试识别；请检查网格贴合，识别失败可使用手动校准。主世界地图视角不在本版支持目标内。

报错前带有 `[SS-类别-编号]`。反馈时请保留完整编号和文字，并说明操作、关卡和分辨率；游戏目录的 StarSketch.log 记录相同定位编号和具体诊断。自动定位失败时可返回普通游戏视角后点“重新识别”，或临时选择相机（默认 Shift+G）。

本地 2026-10-29 版本在报错提示旁提供“汇报错误”。弹窗先引导使用 Shift+G（改键后显示当前按键）检查能否检测到相机，也可点“先检查相机”。仍无法检测或无法贴合时，点击“打开游戏目录并复制邮箱”：实际游戏安装目录会打开，`xlwpy@qq.com` 同时复制到剪贴板。将目录中的 `StarSketch.log` 添加为邮件附件，粘贴收件人并说明操作、关卡和分辨率后发送。打开目录或复制失败会分别提示，可重试；插件不会替用户发送邮件。

“一键复制诊断信息”会复制游戏输出分辨率、窗口尺寸和模式、Windows 版本与架构、处理器数量与内存、游戏使用的显卡和驱动、插件版本、已确认的关卡标识、相机按键、候选数量以及完整错误/当前状态。将这段文本粘贴到邮件正文，再补充触发操作并添加日志附件。取不到的项目明确标记“未取得”；不包含用户名、安装路径、完整矩阵或绘画数据。两个复制按钮都会替换剪贴板内容，请分别粘贴收件人和正文。

自动定位优先采用正常方向的新相机帧，并优先主视图用途提示。只取得已知辅助用途时显示 `[SS-GRID-013]`，请重新识别，或在临时选择相机中手动检查；辅助视图不保证仅靠翻转就能贴合。若只有方向检查失败、其余检查通过，则显示候选网格；首次遇到该类方向时提示 `[SS-GRID-011]`，暂停吸附与染色，并展开“网格精调”。使用“上下翻转”“左右翻转”检查贴合，也可“恢复原始方向”，然后点击“确认并记住”。方向选项随设置保存，同类方向下重新进入或重启后复用，正常方向相机不会继承另一类异常相机的翻转；不保存临时网格几何，也不移动已有标注。若没有拿到可用新帧，仍可能报 011 而无法显示候选。位置、格距或透视仍不对时，请重新识别或临时选择相机。

可视化安装器及已安装的 StarSketch-Manager 管理入口打开时会检查 GitHub 新版，也可点击“检查插件更新”；确认后自动下载校验并更新。更新前先退出游戏。旧 0.1.2 管理器需先使用新版完整安装包更新一次。
