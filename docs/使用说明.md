# 沉星草稿 StarSketch 0.1.4 测试版

退出游戏后，将 dxgi.dll 和整个 StarSketch-assets 文件夹放到 sinking_star.exe 同级目录，保留说明与许可证，照常从 Steam 启动。
若已经安装其他使用 dxgi.dll 的模组，请先处理兼容性，不要直接覆盖。

E 进入/退出绘画；B 画笔；A 箭头；P 编号星标；左键操作；按住右键擦除；G 网格和吸附；T 全屏半透明棋盘染色；Shift+G 四点透视校准；C 清空标记但保留网格和染色；Ctrl+Z/Y 撤销/重做；Esc 取消或返回。工具键只在绘画模式生效，没有使用 F1–F12。

自动网格读取当前关卡、角色高度与相机透视。每次 E 打开草稿纸自动定位；分辨率变化并稳定 250ms 后自动重新定位。连续切换使用最新尺寸，等待和失败时暂停旧网格吸附及染色。一般绘画期间网格冻结。网格精调提供高度覆盖与恢复角色层，另有三点/四点手动校准。已有标记固定屏幕，退出游戏不保存。IME 只在本游戏窗口内禁用。

当前只核验 r67271 / Steam Build 26006400 的一个小关卡和 3840×2160。其他关卡、分层角色和分辨率尚未全面验证；版本不匹配时使用手动校准。主世界地图视角不在本版支持目标内。

报错前带有 `[SS-类别-编号]`。反馈时请保留完整编号和文字，并说明操作、关卡和分辨率；游戏目录的 StarSketch.log 记录相同定位编号和具体诊断。自动定位失败时可返回普通游戏视角后点“重新识别”，或按 Shift+G 手动校准。

自动定位会拒绝方向翻转的相机候选；没有取得正常结果时提示 `[SS-GRID-011]` 并暂停旧网格吸附与染色，可重新识别或手动校准。

可视化安装器及已安装的 StarSketch-Manager 管理入口打开时会检查 GitHub 新版，也可点击“检查插件更新”；确认后自动下载校验并更新。更新前先退出游戏。旧 0.1.2 管理器需先使用新版完整安装包更新一次。
