# 沉星草稿 StarSketch 0.2.0 测试版

推荐下载并完整解压 StarSketch-0.2.0-installer.zip，打开 StarSketch-安装卸载.exe（或同目录 CMD），选择直接包含 sinking_star.exe 的游戏文件夹，保存进度并退出游戏后点击“检查目录”和“安装 / 更新”。0.1.2 用户也可直接升级，无需先卸载；旧版管理器没有在线更新功能，先使用新版完整安装器更新一次。

选择手动安装时，解压 StarSketch-0.2.0-r67271-test.zip，退出游戏后将 dxgi.dll 和整个 StarSketch-assets 文件夹放到 sinking_star.exe 同级目录，保留说明与许可证，照常从 Steam 启动。请下载玩家 ZIP，而非 GitHub 自动生成的 Source code 源码包。
若已经安装其他使用 dxgi.dll 的模组，请先处理兼容性，不要直接覆盖。

E 进入/退出绘画；B 画笔；A 箭头；P 星标；N 独立编号（黑边白字、加粗衬线字体）；N+C 后续编号从 1 开始并保留原标记；左键操作；按住右键擦除；G 网格和吸附；T 全屏半透明棋盘染色；Shift+G 四点透视校准；C 清空标记但保留网格和染色；Ctrl+Z/Y 撤销/重做；Esc 取消或返回。默认工具键只在绘画模式生效，没有占用 F1–F12。

在 E 呼出的工具栏点击“键位与设置”，点击对应按键后输入新组合，可搭配 Ctrl/Alt/Shift，也支持 F1–F12，以及 N+C 这样的两个普通键；单键松开确认，双键同时按住录入。冲突以 [SS-INPUT-001] 提示并保留原键位，Esc 取消录入/关闭窗口，可恢复默认。进入/退出键也能更改，提示同步显示；擦除可改为键盘键或鼠标右/中键，绘制/放置仍使用左键。

红、白、蓝为固定基础色，后两个色格在“键位与设置”→“画笔、标记与颜色”中通过 RGB、HEX 或拾色器自定义；画笔、箭头与无编号金边星标共用此选色，已有标记不随色格变化。独立编号固定黑色描边、白色加粗衬线字，参考游戏界面字形；默认 N 切换，点击放置，从 1 递增，擦除不重排，清空重置，撤销/重做恢复序号。在网格吸附开启且已确认时，编号工具支持按住左键滑动连续编号，快速跨格自动补齐，一次拖动每格只放一次；整次拖动合为一次撤销。未开启吸附或定位尚未确认时仍为单击放置。拖过工具栏或画布外暂停，回到画布后从当前格继续，不补连接空档。

同时按住 N+C 可将下一次编号重置为 1，已有编号保留，重置可撤销/重做；先按 N 或先按 C 均可，不会清空标记。默认 N 和 C 单独操作在松开时确认。重置动作也可在“键位与设置”中另设组合，或点击工具栏“编号从 1 开始”。

星标与编号分别调整大小。按键、自动清除开关、颜色、画笔/橡皮/标记大小、透明度及网格/染色开关会自动保存到 `%LOCALAPPDATA%\StarSketch\settings.ini`，下次启动恢复。草稿、撤销历史和临时网格校准不保存。

“键位与设置”统一放置不常用的大小、透明度与自定义色。网格精调放在主界面，仅开启“网格与吸附”时显示，点击标题展开；尚无可用网格时精调控件禁用。“切换关卡自动清除标注”初始默认关闭，开启后退出绘画仍会监测；新关卡特征通过校验并稳定确认后清空标记、从 1 编号，可撤销。加载中或无法确认时保留标注，重新打开草稿纸和改变分辨率不会被当作切换关卡。未验证的游戏版本不能自动监测，仍可按 C 手动清空。

自动网格读取当前关卡、角色高度与相机透视。每次使用进入键（默认 E）打开草稿纸自动定位；分辨率变化并稳定 250ms 后自动重新定位。连续切换使用最新尺寸，等待和失败时暂停旧网格吸附及染色。一般绘画期间网格冻结。网格精调提供高度覆盖与恢复角色层，另有三点/四点手动校准。已有标记固定屏幕，退出游戏不保存。IME 只在本游戏窗口内禁用。

当前只核验 r67271 / Steam Build 26006400 的一个小关卡和 3840×2160。其他关卡、分层角色和分辨率尚未全面验证；版本不匹配时使用手动校准。主世界地图视角不在本版支持目标内。

报错前带有 `[SS-类别-编号]`。反馈时请保留完整编号和文字，并说明操作、关卡和分辨率；游戏目录的 StarSketch.log 记录相同定位编号和具体诊断。自动定位失败时可返回普通游戏视角后点“重新识别”，或使用四点校准（默认 Shift+G）。

自动定位会拒绝方向翻转的相机候选；没有取得正常结果时提示 `[SS-GRID-011]` 并暂停旧网格吸附与染色，可重新识别或手动校准。

可视化安装器及已安装的 StarSketch-Manager 管理入口打开时会检查 GitHub 新版，也可点击“检查插件更新”；确认后自动下载校验并更新。更新前先退出游戏。旧 0.1.2 管理器需先使用新版完整安装包更新一次。
