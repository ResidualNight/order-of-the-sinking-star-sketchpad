# StarSketch 可视化安装 / 更新 / 卸载工具

需要 Windows x64，自带的 Windows PowerShell 5.1 和 .NET 即可运行。

1. 完整解压安装工具 ZIP，不要只复制或在压缩包里打开某一个脚本。
2. 双击“StarSketch-安装卸载.exe”打开图形窗口，也可使用同目录的 CMD 脚本启动。
3. 浏览选择或粘贴沉星之序的游戏安装文件夹，里面应直接包含 sinking_star.exe。
4. 保存进度并退出游戏，再点击“安装 / 更新”或“卸载草稿纸”。窗口会显示结果。
5. 安装成功后照常从 Steam 启动游戏，按 E 打开草稿纸。

窗口打开时自动从本项目 GitHub Release 检查更新，也可点击“检查插件更新”。正式版和 -test 测试版按数字版本比较，发现新版后显示当前/新版本并询问；选择“是”后下载、校验、一键更新，选择“否”不改动安装。没有新版时显示无需更新。联网检查在后台运行，失败会显示 SS-UPDATE 错误编号，仍可使用本地安装与卸载。

安装后，游戏目录里的 StarSketch-Manager 文件夹也保留管理入口。即使删除下载的安装包，仍可从这里打开“StarSketch-安装卸载.cmd”在线更新或卸载。旧 0.1.2 管理器没有在线更新功能，需先下载 0.1.3 或更新的安装器更新一次。

在线更新只下载本项目官方 HTTPS 发布文件，校验 GitHub 资产摘要（有提供时）、安装 ZIP 的 SHA256、包内版本、DLL 哈希及全部负载。未知 ZIP 路径、重复条目、链接和过大文件会被拒绝。下载和解包暂存于所选游戏目录内的事务目录，失败保留原安装，写入中途失败沿用回滚。下载的新脚本不会被直接执行；安装后的管理入口随插件同步更新。

工具会检查路径、安装包文件完整性和游戏运行状态。其他模组或未知来源的 dxgi.dll 会阻止安装，不会自动覆盖。已知手动安装的 0.1.1 / 0.1.2 可更新或卸载；手动版卸载只处理已识别的 DLL 和原字体，旧说明与许可证可能保留。

安装会写入 dxgi.dll、StarSketch-assets、StarSketch-Manager 和 StarSketch-install.json。卸载按安装记录校验，只处理这些已登记且内容未修改的文件；发现修改或路径链接时会停止。目录里的其他文件和存档保留。安装或卸载中途失败会尝试还原本次改动。

如果回滚也失败，错误提示会给出保留的备份目录；不要手动删除它。空目录清理失败以 SS-INSTALL-038 提示，不再影响备份保留。界面也会显示其他暂存清理警告，方便反馈时提供完整编号和路径。

该工具不修改系统执行策略，不要求安装 Python，也不会强制退出游戏。若目录无法写入，窗口会给出错误；请检查游戏目录权限后重试。

本工具包含 StarSketch 0.1.4 测试版 DLL；本次修复安装器回滚和报错显示，游戏功能延续 0.1.3 的错误编号与网格方向校验；新校验已做数值回归，未实机复现用户的翻转现场。原数据路径验证范围和功能键位见 payload/使用说明.txt。源代码与许可证遵循原项目说明。
