# StarSketch 可视化安装 / 卸载工具

需要 Windows x64，自带的 Windows PowerShell 5.1 和 .NET 即可运行。

1. 完整解压安装工具 ZIP，不要只复制或在压缩包里打开某一个脚本。
2. 双击“StarSketch-安装卸载.exe”打开图形窗口，也可使用同目录的 CMD 脚本启动。
3. 浏览选择或粘贴沉星之序的游戏安装文件夹，里面应直接包含 sinking_star.exe。
4. 保存进度并退出游戏，再点击“安装 / 更新”或“卸载草稿纸”。窗口会显示结果。
5. 安装成功后照常从 Steam 启动游戏，按 E 打开草稿纸。

安装后，游戏目录里的 StarSketch-Manager 文件夹也保留管理入口。即使删除下载的安装包，仍可从这里打开“StarSketch-安装卸载.cmd”卸载；更新则需使用完整新版安装包。

工具会检查路径、安装包文件完整性和游戏运行状态。其他模组或未知来源的 dxgi.dll 会阻止安装，不会自动覆盖。已知手动安装的 0.1.1 / 0.1.2 可更新或卸载；手动版卸载只处理已识别的 DLL 和原字体，旧说明与许可证可能保留。

安装会写入 dxgi.dll、StarSketch-assets、StarSketch-Manager 和 StarSketch-install.json。卸载按安装记录校验，只处理这些已登记且内容未修改的文件；发现修改或路径链接时会停止。目录里的其他文件和存档保留。安装或卸载中途失败会尝试还原本次改动。

该工具不修改系统执行策略，不要求安装 Python，也不会强制退出游戏。若目录无法写入，窗口会给出错误；请检查游戏目录权限后重试。

本工具包含已验证的 StarSketch 0.1.2 测试版 DLL。游戏支持范围和功能键位见 payload/使用说明.txt。源代码与许可证遵循原项目说明。
