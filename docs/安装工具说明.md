# StarSketch 可视化安装 / 更新 / 卸载工具

需要 Windows x64，自带的 Windows PowerShell 5.1 和 .NET 即可运行。

1. 下载并完整解压 StarSketch-0.2.1-installer.zip，不要下载 GitHub 的 Source code 源码包，也不要只复制 EXE 或在压缩包里直接打开。
2. 双击“StarSketch-安装卸载.exe”打开图形窗口，也可使用同目录的 CMD 脚本启动。
3. 浏览选择或粘贴沉星之序的游戏安装文件夹，里面应直接包含 sinking_star.exe。可在 Steam 库中右键游戏 → 管理 → 浏览本地文件找到它；点击“检查目录”核对安装状态。
4. 保存进度并退出游戏，再点击“安装 / 更新”或“卸载草稿纸”。窗口会显示结果。
5. 安装成功后照常从 Steam 启动游戏，按 E 打开草稿纸。

## 现有 0.1.2 用户怎么操作

请下载并完整解压新版可视化安装包，使用新版窗口选择原游戏文件夹，点击“检查目录”。窗口会区分 0.1.2 手动复制版和可视化安装版，并给出对应操作。

| 目的 | 在新版可视化安装器中的操作 |
| --- | --- |
| 0.1.2 更新到本包版本 | 保存进度、退出游戏，选择原游戏目录，直接点击“安装 / 更新”。无需先卸载，也不需要重装游戏；旧 DLL、字体与管理入口按归属检查后更新。 |
| 直接卸载 0.1.2 | 保存进度、退出游戏，选择原游戏目录，点击“卸载草稿纸”。无需先更新；结果会显示已卸载的版本。 |
| 原 0.1.2 管理入口没有更新按钮 | 旧入口不具备在线更新功能，请先用新版完整安装包完成一次更新；之后使用游戏目录里的新 StarSketch-Manager 管理入口。 |
| 0.1.2 原下载包已删除 | 无需找回旧包，新版完整安装器可识别并更新/卸载原安装。升级后的已安装管理入口也能在删除下载包后独立卸载。 |

可视化安装的 0.1.2 按原安装记录检查和处理文件。手动复制的 0.1.2 按已知 DLL SHA256 与原字体校验，只移除确认属于草稿纸的 DLL 和原字体；根目录的旧说明、许可证及自行添加的文件保留。游戏、存档及其他模组文件保留。

发现未知 DXGI、改过的字体/已登记文件或路径链接时，窗口会提示错误编号并停止，不强行覆盖或删除。更新或卸载中途失败会回滚本次修改。游戏运行时拒绝操作，请先正常退出。

## 在线检查与管理入口

窗口下方常驻“无法自动更新？打开 GitHub 发布页手动下载”链接，点击后用默认浏览器打开项目官方 Releases 页面（包含测试版）。自动检查或下载更新失败时，操作结果会提示使用此入口；手动下载完整安装 ZIP，解压、正常退出游戏，再运行新安装器点击“安装 / 更新”。若默认浏览器无法启动，结果框提供可复制的网址。已安装管理入口也提供相同链接。

窗口打开时自动从本项目 GitHub Release 检查更新，也可点击“检查插件更新”。正式版和 -test 测试版按数字版本比较，发现新版后显示当前/新版本并询问；选择“是”后下载、校验、一键更新，选择“否”不改动安装。没有新版时显示无需更新。联网检查在后台运行，失败会显示 SS-UPDATE 错误编号，仍可使用本地安装与卸载。

安装后，游戏目录里的 StarSketch-Manager 文件夹也保留管理入口。即使删除下载的安装包，仍可从这里打开“StarSketch-安装卸载.cmd”在线更新或卸载。旧 0.1.2 管理器没有在线更新功能，需先下载 0.1.3 或更新的安装器更新一次。

本地新版修复 GitHub 网页正常但 API 检查返回 403 的情况：API 联网失败、限流或拒绝访问时，自动尝试本项目官方发布订阅（包含测试版），再检查新版官方附件是否存在及大小，确认更新后仍校验清单、ZIP、DLL 和全部负载。备用订阅仅包含 GitHub 当前提供的近期发布；订阅无法识别或附件大小未知时会报错，不猜测版本或跳过校验。API 元数据格式/安全校验失败时不使用备用源绕过检查。

若仍无法检查，SS-UPDATE-013 表示请求额度耗尽/限流，能取得恢复时间时会显示；SS-UPDATE-014 表示其他 403 拒绝。浏览器访问 github.com 成功并不代表 api.github.com 仍有额度或使用相同代理规则。旧管理器需要用修复后的完整安装包更新一次才能获得此修复；也可先使用本地“安装 / 更新”，后台联网失败不影响离线操作。

在线更新只下载本项目官方 HTTPS 发布文件，校验 GitHub 资产摘要（有提供时）、安装 ZIP 的 SHA256、包内版本、DLL 哈希及全部负载。未知 ZIP 路径、重复条目、链接和过大文件会被拒绝。下载和解包暂存于所选游戏目录内的事务目录，失败保留原安装，写入中途失败沿用回滚。下载的新脚本不会被直接执行；安装后的管理入口随插件同步更新。

工具会检查路径、安装包文件完整性和游戏运行状态。其他模组或未知来源的 dxgi.dll 会阻止安装，不会自动覆盖。已知手动安装的 0.1.1 / 0.1.2 可更新或卸载；手动版卸载只处理已识别的 DLL 和原字体，旧说明与许可证可能保留。

安装会写入 dxgi.dll、StarSketch-assets、StarSketch-Manager 和 StarSketch-install.json。卸载按安装记录校验，只处理这些已登记且内容未修改的文件；发现修改或路径链接时会停止。目录里的其他文件和存档保留。安装或卸载中途失败会尝试还原本次改动。

如果回滚也失败，错误提示会给出保留的备份目录；不要手动删除它。空目录清理失败以 SS-INSTALL-038 提示，不再影响备份保留。界面也会显示其他暂存清理警告，方便反馈时提供完整编号和路径。

该工具不修改系统执行策略，不要求安装 Python，也不会强制退出游戏。若目录无法写入，窗口会给出错误；请检查游戏目录权限后重试。

本包包含 StarSketch 0.2.1 测试版 DLL，修复半分辨率相机筛选与线程栈扫描，新增游戏内后台更新检查。有新版时主面板顶部以绿色文字提醒退出游戏后使用安装器更新；无更新或联网失败时不显示。保留改键和设置持久保存、自定义颜色、金边星标、独立连续编号及可选的跨关卡自动清除，并提供 0.1.2 迁移支持。网格实机验证范围未扩大。功能键位见 payload/使用说明.txt；已安装管理入口位于游戏目录的 StarSketch-Manager。源代码与许可证遵循原项目说明。

键位与偏好保存在当前 Windows 用户的 `%LOCALAPPDATA%\StarSketch\settings.ini`，更新和卸载不会删除用户偏好；画线、星标、编号和校准不保存。新版自动清除初始默认关闭，可在游戏内“键位与设置”开启并记住选择。
