# 更新记录

## 0.2.0 测试版 — 2026-10-25

- 安装器和已安装管理入口增加常驻 GitHub 发布页链接，在线检查或更新失败时提示手动下载完整安装包；默认浏览器无法启动时提供可复制的网址。
- 修复 GitHub 网页可访问、匿名 API 限流却导致安装器更新检查失败：请求失败时尝试官方 Atom 发布订阅及附件 HEAD 检查，保留版本、下载大小和安装哈希校验；限流与其他 403 分别显示 SS-UPDATE-013/014，提供域名和可用的额度恢复时间。
- 入口更名“键位与设置”，移入大小、透明度、自定义色；网格精调位于主界面，仅开启网格与吸附时显示。新增默认关闭且记住选择的关卡自动清除，可信特征稳定后才执行，读取失败保留标记，可撤销。
- 键位和偏好永久保存于当前用户本地设置文件，采用校验、延迟写入、正常关闭时刷新、原子替换及损坏文件备份；草稿与校准仍不保存。

- 编号在可信网格吸附下支持按住左键滑动，跨格补齐、单次拖动去重和整组撤销；新增 N+C 保留原标记并将后续编号归 1，可改键与撤销，处理双键优先避免误清空。

- 新版可视化安装器明确识别 0.1.2 手动版/安装器版，提示直接更新、直接卸载和旧管理入口的更新方式；新增校验原始发布 ZIP 的专用兼容回归，保持事务回滚与修改文件保护。

- E 呼出的工具栏新增“键位与设置”窗口，支持进入/退出、工具及编辑动作组合键、冲突提示、恢复默认和同步键帽；录入与文本编辑隔离快捷键，设置与键位永久保存，草稿仍只保留当前会话。
- 红、白、蓝保留基础色，后两个色格支持 RGB/HEX/拾色器自定义；画笔、箭头、星标共用选色，已有标记保持原色。
- P 改为无编号星标，内部与画笔共色，外沿采用带明暗斜面和双层厚重阴影的复古金边；新增默认 N 独立递增编号，参考游戏衬线数字字形，白色加粗内芯与黑色外描边，支持预览、吸附、擦除、撤销/重做和独立大小。
- 发布标签为 `v0.2.0-test`，可视化与手动包使用同一 0.2.0 DLL；发布说明包含首次安装、0.1.2 直接升级和在线更新失败后的手动下载方法。

## 0.1.4 测试版 — 2026-10-24

- 修复安装回滚与空目录清理同时失败时可能删除恢复备份的问题；先确定备份保留，再独立处理清理异常，以 SS-INSTALL-038 提示。
- 图形窗口显示同步操作和后台更新的清理警告；后台直接抛出的异常保留原始 SS-UPDATE / SS-INSTALL 编号，避免被 EndInvoke 包装为通用错误。
- 补充二次故障、后台管理器更新自身及终止异常的隔离回归。游戏功能沿用 0.1.3，仅同步运行时版本标记，未扩大实机网格验证范围。

## 0.1.3 测试版 — 2026-10-24

- 图形安装器和已安装管理入口新增“检查插件更新”，打开窗口时后台检查本项目 GitHub Release，包含 -test 测试版；发现新版询问，确认后一键下载、校验及更新，取消不改动安装。
- 更新校验官方地址、GitHub 摘要、ZIP SHA256、文件布局及版本/DLL 身份，沿用运行中保护、所有权检查与事务回滚，原下载包删除后仍可更新或卸载。旧 0.1.2 管理器需先下载本版安装器更新一次。
- 增加自动网格方向校验，拒绝上下/左右镜像及整体倒置的相机候选，正常镜头水平旋转仍可通过；未取得正常新帧时以 SS-GRID-011 提示。网格转换再次校验，手动校准保持原有行为。
- 玩家可见报错统一在最前面显示稳定的 `[SS-类别-编号]`，提供错误代码查询表，并纳入后续开发规则。
- 自动定位失败按版本、关卡数据、角色层、相机新帧、关卡切换和投影失败分别提示；相机等待超时区分“无校验通过的候选”和“候选未产生有效新帧”。界面和日志使用同一编号，日志附渲染尺寸。
- 图像诊断、校准失败、渲染/挂钩日志及安装器异常同步补充编号；安装回滚外层保留结果编号及内部原因，未知系统异常有兜底编号。
- 新增在线更新隔离回归。旧定位截图的具体根因及用户翻转现场尚未实机确认，不扩大自动定位的实机支持范围。

## 可视化安装工具 — 2026-10-23

- 继续使用原 0.1.2 测试版 DLL，未改变游戏功能或扩大网格支持范围。安装器验证细节见验证记录。

## 0.1.2 测试版 — 2026-10-22

- 每次打开草稿纸都自动按游戏数据定位，包括首次打开、隐藏网格和曾手动校准的情况。
- 检测渲染/画布尺寸变化，稳定 250ms 后自动定位；连续切换取消旧请求并使用最新尺寸。
- 定位期间暂停旧网格的吸附与染色；手动校准/精调可取消正在等待的定位。
- 保持标记、编号、撤销历史和网格/染色开关；尺寸变化时按比例换算标记。
- 增加界面生命周期回归并接入 build.ps1。实机覆盖以验证记录为准。

## 0.1.1 测试版 — 2026-10-22

- 用只读游戏数据和相机投影替代游戏运行路径中的图像周期识别，处理斜俯视透视。
- 增加完整游戏文件哈希、类型、数组、视口、逆矩阵、新帧与关卡切换校验。
- 默认使用角色高度层，可覆盖高度并恢复角色层；定位失败暂停旧自动吸附。
- 网格在绘画期间冻结，已有标记始终固定屏幕；再次进入绘画时刷新数据网格。
- 实机和数值回归结果见 [验证记录](验证记录.md)。

## 0.1.0 原型 — 2026-10-22

- 独立 DXGI/DX12 加载与绘制。
- 画笔、右键局部擦除、箭头、自动编号星标、撤销/重做与 C 清空。

- 修正重复快捷键、鼠标事件、字号裁切与星标预览遮挡。
