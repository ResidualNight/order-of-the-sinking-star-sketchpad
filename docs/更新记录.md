# 更新记录

## 可视化安装工具 — 2026-10-23

- 新增深蓝/金色安装窗口，提供目录浏览、路径输入、检查、安装/更新和卸载。
- 在同一 0.1.2 测试版 Release 补充图形安装 ZIP，原手动复制 ZIP 和校验清单继续保留；README 和 Release 分别说明两种安装、更新与卸载方式。
- 包内提供图形 EXE 与 CMD 入口；游戏目录保留独立卸载管理脚本。
- 增加已知手动版本识别、安装归属记录、SHA256 校验、运行中游戏保护及事务回滚。
- 外部 DXGI、已修改文件、路径穿越、目录链接、并发修改和中途失败均有隔离回归覆盖。
- 继续使用原 0.1.2 测试版 DLL，未改变游戏功能或扩大网格支持范围。安装器验证细节见验证记录。

## 0.1.2 测试版 — 2026-10-22

- 每次打开草稿纸都自动按游戏数据定位，包括首次打开、隐藏网格和曾手动校准的情况。
- 检测渲染/画布尺寸变化，稳定 250ms 后自动定位；连续切换取消旧请求并使用最新尺寸。
- 定位期间暂停旧网格的吸附与染色；手动校准/精调可取消正在等待的定位。
- 保持标记、编号、撤销历史和网格/染色开关；尺寸变化时按比例换算标记。
- 增加界面生命周期回归并接入 build.ps1。实机覆盖以验证记录为准。

## 0.1.1 测试版 — 2026-10-22

- 用只读游戏数据和相机投影替代游戏运行路径中的图像周期识别，处理斜俯视透视。
- 增加完整游戏文件哈希、类型、数组、视口、逆矩阵、新帧与关卡切换校验。
- 默认使用角色高度层，可覆盖高度并恢复角色层；定位失败暂停旧自动吸附。
- 网格在绘画期间冻结，已有标记始终固定屏幕；再次进入绘画时刷新数据网格。
- 实机和数值回归结果见 [验证记录](验证记录.md)。

## 0.1.0 原型 — 2026-10-22

- 独立 DXGI/DX12 加载与绘制。
- 画笔、右键局部擦除、箭头、自动编号星标、撤销/重做与 C 清空。
- 半透明全屏棋盘染色、三点与四点透视校准、工具栏精调。
- 游戏风格键帽、衬线字体、金边星芒图钉。
- 绘画输入隔离，以及仅限游戏窗口的 IME 禁用。
- 修正重复快捷键、鼠标事件、字号裁切与星标预览遮挡。
